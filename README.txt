CLAUDE SKILLS LIBRARY
=====================
Unique skills: 2507
Duplicates removed: 121

STRUCTURE
  skills\<name>\SKILL.md      each skill is a folder with its SKILL.md (+ scripts/refs)
  _licenses\                  original LICENSE file from every source repo
  CREDITS.txt                 source repos, licenses and copyright notices

HOW TO USE
  Claude Code (personal):  copy a folder from skills\ into  ~/.claude/skills\
  Claude Code (project):   copy into  .claude/skills\  inside your repo
  Claude.ai web:           zip a skill folder and upload under Customize > Skills
